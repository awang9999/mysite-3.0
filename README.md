# mysite-3.0

The third iteration of my personal website: **clean and straight to the point, with subtle design choices that make it comfortable to read and look at.** No fluff — the previous site had too much of it.

## Pages

- **Home** — hero (name, one-line role, links)
- **About** — who I am
- **Experience** — work history
- **Projects** — the curated featured set + the full archive, all in one ordered list
- **Blog** — index + posts

## The agent team

This repo is developed by a small team of agentic personas in `.pi/agents/`, each with one job:

| Agent | Owns | Ask it to… |
|---|---|---|
| `art-director` | `docs/DESIGN.md` + visual direction | design a page, pick type/color/spacing, critique how something looks |
| `editor` | `content/` + every word on the site | write or trim copy, curate the project list, draft blog posts |
| `builder` | site code within static-first constraints | implement pages/components, keep JS near zero, keep it fast |
| `ops` | `docs/HOSTING.md` + `deploy/` + live AWS config | deploy, manage S3/CloudFront/DNS, fix caching |

Shared rules live in the docs, not in chat:

- `docs/HOSTING.md` — how the site is hosted (static on S3 + CloudFront; verified current AWS state; migration plan; open questions)
- `docs/DESIGN.md` — the design system (seeded; art-director owns it)
- `content/` — all site content as data (editor owns it)

## Workflow

1. Develop with a local dev loop — `npm run dev` (port 4321)
2. **Preview the built output locally** (no AWS credentials — required before every deploy, see `docs/HOSTING.md` §10) — `npm run build && npm run preview`
3. `./deploy/deploy.sh` → build, sync to S3, invalidate CloudFront, verify

### Build notes

- `npm run build` = `astro build` + a KaTeX finalizer (`scripts/finalize-katex.mjs`):
  it subsets the KaTeX font faces to the exact glyphs the current posts use,
  trims the KaTeX CSS, content-hashes everything into `dist/_astro/`, and
  drops the full dev-time KaTeX copy. Requires `python3` + `fontTools`
  (`pip install fonttools`) on the build machine.
- Fonts: Manrope (variable WOFF2, `latin` + `latin-ext` subsets) is self-hosted
  in `src/assets/fonts/`; code uses the system monospace stack. No font CDN.
- `content/` is the single source of truth for all copy — the build wires it
  in via Astro content collections (`src/content.config.ts`); nothing in `src/`
  duplicates copy.
- The dev-only KaTeX copy in `public/katex/` is generated by
  `npm run vendor:katex` (runs on install) and is gitignored.

## Stack

**Astro 7** (D12) — markdown-first SSG: plain multi-page HTML, zero JS by default, real URLs (D3), content-hashed assets (D5), built-in `dev` / `build` / preview (§10). Blog math is **KaTeX rendered at build time** (D11). Deployment is a local script — no CI (D4).
